Local backend

The optional Rust backend (office-backend) runs on your own computer. It opens .doc, .rtf and .odt files, gives the most faithful .docx/.xlsx/.pptx results (including Excel charts) and, when a LaTeX engine such as TeX Live, MiKTeX or Tectonic is installed, compiles LaTeX documents to PDF. Without it the editor still opens and saves .docx, .xlsx, .xls, .ods, .csv, .tsv, .pptx, .tex, .md and .txt with its built-in engines.

This address is not on this computer. Every document you open will be uploaded to it. Only use a server you control.

How to start the backend
  1. Install Rust from rustup.rs (once).
  2. Start the backend from the project's src folder:
    • Windows: double-click src\run-backend.bat (or run powershell -ExecutionPolicy Bypass -File src\run-backend.ps1)
    • macOS / Linux: ./src/run-backend.sh
    • Any system: cd src then cargo run --release -p office-backend
  3. Keep that window open while you work. It listens on 127.0.0.1:47831; to use another port set OFFICE_BACKEND_ADDR=127.0.0.1:PORT (or pass the port to the run-backend script) and enter the same address above.
  4. Click Test connection.

Websites

Checking…

To open documents from websites the extension needs permission to read the files you open from those sites. It is only used for document links and downloads, never for anything else.

Right-click any document link and choose Open in Office Editor to open it regardless of these settings.

Files on this computer

Use Open file… in the toolbar popup or the editor (this keeps a link to the file, so Save writes straight back to it), or drag files onto an editor tab. “Open with” from the operating system only works on ChromeOS.

Checking…

Optional: turn on Allow access to file URLs on the extension's details page to open Office files that you drag into the browser window (file:// addresses) in the editor.
